Pill-shaped call-to-action button, used for primary site actions (Join, Donate, Find a Trail).

```jsx
<Button variant="primary" size="m" onClick={() => {}}>Find a Trail</Button>
<Button variant="secondary">Donate</Button>
<Button variant="outline">Learn More</Button>
```

Variants: `primary` (forest green, main actions), `secondary` (blaze orange, donate/urgent), `outline` (quiet actions on light surfaces), `ghost` (inline/nav actions). Sizes: `s`, `m`, `l`. Disabled state dims to 45% opacity.
