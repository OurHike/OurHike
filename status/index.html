Is the map working?

This page checks OurHike's map data from your own browser, right now — not from a server, and not from a report written earlier.

Checking…

Asking the data bucket the same questions the app asks.

    Two things this page cannot tell you, worth saying plainly rather than implying more coverage than it has.

    It is served from the same place as the app. If GitHub Pages itself is down, this page goes down with the thing it reports on — so reaching it at all already rules one failure out, and rules nothing else in.

    It needs a connection. OurHike is built to work without one, so if you are on the trail with a downloaded map, none of this affects you: the map on your phone does not ask anything of a server. This page is for the person at a trailhead on wifi, wondering whether it is worth starting a download.
