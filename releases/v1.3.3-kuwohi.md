# v1.3.3 — Kuwohi

_1 change since v1.3.2._

**A hotfix, cut from v1.3.2 rather than from `main`** (RELEASING.md §11a). It
carries one change, and the change is to ourhike.org's homepage, not to the app.
`main` had 91 merges past v1.3.2 when this was cut. None of them are in this
release, and they wait for the next one.

The reason for shipping it alone: REI's affiliate program runs through
impact.com, and Impact will not approve ourhike.org until it can read a
verification line on the live homepage. That homepage only changes when a
release is published. The maintainer chose v1.3.3 as a hotfix by poll on
2026-09-29.

## What is not validated

<!-- RELEASING.md §8d: this section is never empty, and a release whose author believes
     it is has not looked. A hiker deciding whether to trust a direction cue is entitled
     to know the thresholds behind it have never been tested under tree canopy. -->

Two things about the one change, both marked `@unvalidated` in
`site/src/pages/index.astro`:

- **Whether Impact's checker counts text inside a `hidden` element.** Impact's
  help page says the line can go anywhere on the homepage. It does not say
  whether hidden text counts. If verification fails, the fallback is to make
  the line visible small print. That would be a new release.
- **Whether the meta tag's value is right.** Impact showed the maintainer only
  the text line, and the meta tag reuses its id. A wrong value does no harm,
  because the text line does not depend on it.

Everything [v1.3.2's notes](https://github.com/OurHike/OurHike/releases/tag/v1.3.2)
list under this heading is still true. This release changes none of the app code
it describes.
