# Website UI Kit

Recreation of the OurHike marketing homepage: dark-pine nav header, hero with CTA pair, featured-trail card grid (using Badge difficulty tags), a membership Callout banner, and the multi-column footer.

Composed entirely from `components/core`, `components/forms`, `components/navigation`, `components/feedback` — no one-off styling.

Caveat: built from public site copy and mission content (no Figma/codebase access), so layout is an original interpretation of the brand, not a pixel trace. See root `readme.md` for details.
